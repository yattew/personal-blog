# Browser Inspect & Debugging Skill

This skill guides automated inspection and live testing of the personal blog in Google Chrome.

## Available Capabilities
- Launch and navigate Chrome to local dev (`http://localhost:8000`) or production (`https://yattew.github.io/personal-blog/`).
- Inspect DOM elements, computed CSS styles, and layout shifts.
- Capture full-page or element-level screenshots.
- Check browser console logs, JavaScript errors, and network performance.
- Simulate user interactions (clicks on theme buttons, copying swatches, viewport resizing).
